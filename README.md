# 応急給水拠点マップ（試作サンプル）

災害時の応急給水拠点を、現地でスマートフォンから登録し、地図上で共有・管理するためのアプリの**試作版**です。
仕様検討・画面イメージの確認を目的としたもので、データは**端末のブラウザ内にのみ**保存されます。

> 「現在地を取得」が動作しません（許可ダイアログすら出ません）。

## 使い方

画面は左（スマホでは上）が入力パネル、右（スマホでは下）が地図です。
パネル上部の4つのタブを切り替えて操作します。

### 1. 登録・編集 — 拠点を地図に登録する

**① 座標を指定する**（3通りのいずれか。必須項目です）

| 方法 | 操作 | 向いている場面 |
| --- | --- | --- |
| 現在地を取得 | 「📍 現在地を取得」を押し、ブラウザの許可ダイアログで**許可** | 現地に立っているとき |
| 写真のGPS | 「写真」から撮影済みの画像を選択。EXIFのGPSを自動で読み取り | 現地で撮った写真から後で登録するとき |
| 地図をクリック | 「🖱 地図クリックで座標を指定」をONにして地図上をタップ | 事務所で台帳から登録するとき |

登録後も、地図上のマーカーを**ドラッグ**して位置を微調整できます。

**② 情報を入力する**

- **位置精度レベル** — 座標の確からしさを6段階で記録（5:実測・写真GPS〈誤差数m〉／4:現地で地図クリック／3:住所から特定／2:街区レベル／1:町丁目レベル／0:不明）※定義は暫定案
- **拠点の基本情報** — 施設番号／施設名称／区分（応急給水・仮設給水所・井戸・飲料水配布・生活用水配布）／飲用可否／住所
  - 施設番号が既存の拠点と重複すると警告が出ます
- **開設の状況** — 開設状況／開設日・閉鎖日／開設時間／**タンク容量（L）**（残量%の計算に使用）
- **写真・その他** — 写真（複数枚可・長辺1600pxに自動縮小）／備考／参照URL／登録者名

**③「➕ 地図に登録」**を押すと地図にピンが立ちます。

既存の拠点を編集するときは、地図のマーカーまたは一覧から「編集」を選びます。編集中は「編集をやめる」「この拠点を削除」が表示されます。

### 2. 一覧 — 登録した拠点を探す

名称・住所・施設番号・備考でのキーワード検索と、区分・開設状況での絞り込みができます。
各行から「編集」「🚗 ここへ行く」（Googleマップの経路案内を起動）が使えます。

### 3. 給水記録 — 運用状況を記録する

拠点を選んで、日々の給水オペレーションを記録します。

- **記録の種類** — 補給（給水車から搬入）／配布（市民へ）／点検・巡回
- **搬入量・配布量（L）**、**残量（%）**（スライダー・概算で可）
- **利用者数／容器数**
- **一時的に水が切れた（欠品）** チェック
- 記録者・メモ（行列の状況、対応内容など）

#### 地図の色分け

記録された**残量低下の回数**（残量がしきい値以下 ＋ 欠品の回数）に応じて、マーカーの色が変わります。
どの拠点の供給を増強すべきかを一目で把握するための表示です。

| 色 | 意味 |
| --- | --- |
| 🔵 青 | 0回（余裕あり） |
| 🟡 黄 | 1〜2回 |
| 🟠 橙 | 3〜5回 |
| 🔴 赤 | 6回以上（要増強） |
| ⚪ 灰 | 記録なし |

しきい値（既定20%）は「出力・設定」タブで変更できます。

### 4. 出力・設定

**出力**

| 形式 | 用途 |
| --- | --- |
| CSV：拠点一覧 / 給水記録 | Excelでそのまま開けます（BOM付きUTF-8）。写真は含まれません |
| KML | Googleマイマップに手動でインポートできます |
| GeoJSON | GISツール等での利用 |

いずれも**Googleマップの経路案内URL**を含むため、マイマップに取り込んだ後も各地点から「ここへ行く」が使えます。

**取込・バックアップ**

- **バックアップ（JSON）を保存 / 復元** — データは端末内にしか無いため、定期的な保存を推奨します。**復元すると現在のデータは置き換わります**
- **拠点CSVを取込** — 既存台帳の初期投入用。1行目に見出しが必要で、`緯度` `経度` の列は必須です
  （`施設番号, 施設名称, 区分, 飲用可否, 都道府県, 市区町村, 住所, 緯度, 経度, 位置精度レベル, 開設状況, 開設日, 閉鎖日, 開設時間, タンク容量L, 備考, 参照URL, 登録者`／「CSV：拠点一覧」の出力と同じ形式）
- リポジトリ同梱の [`sample_kumamoto_r8_20260803.json`](sample_kumamoto_r8_20260803.json) をバックアップ復元から読み込むと、熊本市の拠点10件で動作を確認できます（給水記録は入っていないため、マーカーは全て灰色になります。色分けを試すには「動作確認用のダミーデータを入れる」をお使いください）

**表示の設定** — 残量しきい値／地図の背景（下記）／「ここへ行く」の移動手段（車・徒歩・公共交通機関・自転車）

#### 地図の背景（rev3 で海外対応）

| 分類 | 選択肢 | 用途 |
| --- | --- | --- |
| 日本国内（詳細） | 国土地理院 標準地図／淡色地図／航空写真 | **国内はこちらを推奨。**海外にはデータがなく白地図になります |
| 世界 | OpenFreeMap Liberty／Bright／Positron／Dark | **海外拠点はこちら。**全世界をカバーします |
| その他 | OpenStreetMap 標準 | 検証用。利用ポリシー上、本番運用には使えません |

「世界」の地図は [OpenFreeMap](https://openfreemap.org/)（OpenStreetMap ベースのベクタタイル）を使用しています。
APIキー不要・件数無制限・商用利用可で、表示には **WebGL 対応ブラウザ**が必要です。
WebGL が使えない端末では、警告を表示したうえで自動的に国土地理院 標準地図へ切り替わります。

**データの管理** — 使用容量の表示／動作確認用のダミーデータ投入／全データ削除

## ご注意（試作版の制約）

- **データはこの端末のこのブラウザの中だけに保存されます**（localStorage）。他の人とは共有されません。端末の変更やブラウザのデータ削除で消えます
- 保存容量には上限があり、写真を大量に登録すると保存できなくなります
- 複数人での共有・写真の大量保存は、保存先をクラウドにする本開発で対応する想定です
- 選択肢の定義（位置精度レベル、飲用可否など）は**暫定案**です

## 「現在地を取得」が動かないとき

1. **`https://` のURLから開いているか** — 最も多い原因です。ダウンロードしたファイルを直接開いていませんか？
2. **端末の位置情報がONか** — 設定 → 位置情報
3. **ブラウザに位置情報の許可があるか** — Chromeのアドレスバーの鍵アイコン → 権限 → 位置情報
4. **ファイルアプリやSNSの内蔵ブラウザで開いていないか** — Chrome / Safari で開き直してください

上記でも解決しない場合、画面に取得失敗の理由（エラーコード）が表示されますので、その内容をお知らせください。

## 技術構成

単一のHTMLファイルで動作します（ビルド不要）。

- 地図：[Leaflet](https://leafletjs.com/) 1.9.4
- ベクタ地図描画（rev3）：[MapLibre GL JS](https://maplibre.org/) 5.24.0 ＋ [maplibre-gl-leaflet](https://github.com/maplibre/maplibre-gl-leaflet) 0.1.4
- 背景地図：[地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)（国土地理院）／[OpenFreeMap](https://openfreemap.org/)（rev3）／[OpenStreetMap](https://www.openstreetmap.org/)
- 写真のGPS読み取り：[exifr](https://github.com/MikeKovarik/exifr) 7.1.3
- 経路案内：[Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)（**APIキー・課金は不要**）
- データ保存：ブラウザの localStorage

ライブラリはCDNから読み込むため、**初回表示にはインターネット接続が必要**です。

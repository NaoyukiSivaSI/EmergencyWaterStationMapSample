試作サンプル — 使用する版を選んでください

スマートフォンでお使いの場合は、必ずこの https:// のページからお進みください。
HTMLファイルを端末にダウンロードして直接開くと、ブラウザの制約により「現在地を取得」が動作しません。
データはお使いの端末のブラウザ内にのみ保存されます。他の人とは共有されず、ブラウザのデータ削除で消えます。

最新版

rev3最新・推奨

rev2 の全機能 ＋ 海外対応。国土地理院タイルに加えて世界地図（OpenFreeMap）を選べます。

  • 背景地図に「世界」を追加（海外でも地図が表示されます）
  • WebGL が使えない端末では自動的に地理院タイルへ切替

過去の版（比較・検証用）

rev2国内向け

拠点登録・給水記録・出力までひと通り揃った版。背景地図は日本国内のみです。

  • 「🚗 ここへ行く」でGoogleマップの経路案内を起動
  • 「現在地を取得」の失敗理由を画面に表示
  • 写真の自動縮小、拠点の編集・個別削除、CSV／KML／GeoJSON出力
rev2 を開く →
rev1旧版

rev2 の一つ前。タブ構成・給水記録・色分けは同じですが、経路案内がありません。

  • 「ここへ行く」（Googleマップ経路案内）は未搭載
  • 「現在地を取得」が失敗しても理由が表示されません
rev1 を開く →
rev0初版・参考

最初の試作版（2026-08-17）に、地図が表示されなくなっていた不具合の修正のみを加えたものです。

  • 写真は1枚のみ・原寸のまま保存するため、数枚で保存容量を超えます
  • 座標は「写真のGPS」「現在地を取得」の2通りのみ（地図クリック不可）
  • 登録済みデータの編集・個別削除ができません
  • 他の版とは別のデータ領域を使います
rev0 を開く →

ご利用にあたって

rev1・rev2・rev3 は同じ保存領域を共有します。
どの版で登録しても同じデータが表示されるため、版を切り替えながらの比較ができます。
rev0 のみ保存先が異なり、データは共有されません。
大切なデータは「出力・設定」タブからバックアップ（JSON）を保存してください。
rev0 にはバックアップ機能がありません（CSV出力のみ）。
詳しい使い方は README をご覧ください。 ／ リポジトリ
